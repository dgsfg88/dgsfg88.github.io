Conference proceedings
2016
Flavio Bertini; Rajesh Sharma; Andrea Ianni; Danilo Montesi;, Social Media Investigations Using Shared Photos
Collection: International Conference on Computing Technology, Information Security and Risk
Organization: UNIBO
In this paper, we present a method to verify and resolve user profiles in SNs using the images posted on them, assuming taken through user's smartphone. Creating a sort of fingerprint of the user profile, the method is capable enough to resolve profiles in spite of the fact that the images get downgraded during the uploading/downloading process. Also, the method can compare different images belonging to different SNs without using the original images.
